# วิจัยชั้นเรียนเปลี่ยนชีวิต · ปั้น Best Practice ติดปีกด้วย AI

คอร์สออนไลน์แบบ SPA สำหรับครู 6 โมดูล  
ถอดโครงจากหลักสูตรอบรมเชิงปฏิบัติการ 2 วัน 12 ชั่วโมง

## เปิดใช้งานทันที

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม

หรือใช้เซิร์ฟเวอร์สั้น ๆ:

```bash
python3 -m http.server 8080
```

แล้วเข้า [http://127.0.0.1:8080](http://127.0.0.1:8080)

## เปิดเป็นเว็บสาธารณะด้วย GitHub Pages

1. Settings → Pages
2. Source เลือก **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. รอสักครู่ แล้วเข้า `https://thanaded159.github.io/car-ai-course/`

## สิ่งที่อยู่ในคอร์ส

- โมดูล 1 ปลดล็อกโจทย์วิจัย
- โมดูล 2 วงจร PAOR
- โมดูล 3 นวัตกรรมและเค้าโครง CAR 1 หน้า
- โมดูล 4 ข้อมูลและสถิติอย่างง่ายด้วย AI
- โมดูล 5 เขียน Best Practice
- โมดูล 6 Show & Share
- คลัง Prompt 10 ชุด
- ใบงานกรอกได้ บันทึกในเบราว์เซอร์ของผู้เรียน
- แผน 30 วันหลังอบรม
